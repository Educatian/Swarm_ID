# DTS Figma ↔ App 운영 루프

Figma 파일 `4WIyk1eds5QF6B8fV9fpTU`를 UI/UX 설계 기준으로 사용한다.

## 적용 순서

1. `preview.html`과 `app.js`에서 역할·뷰·상태·반응형 변형을 확인한다.
2. 실행 중인 화면을 Figma에 캡처하고, 캡처 노드 이름을 `Current · <route/state>`로 고정한다.
3. Figma `01 · UX Audit & Decisions`에서 정보 우선순위, 텍스트 잘림, 간격, 접근성, 모바일 작업 맥락을 검토한다.
4. Figma `02 · Improved Full App`의 개선안을 기준으로 `styles.css`/`app.js`에 반영한다.
5. 데스크톱·모바일 브라우저를 확인하고 `node scripts/smoke-usability-upgrade.mjs`를 실행한다.
6. 변경된 화면을 다시 캡처해 Figma의 Current 캡처와 비교하고, 불일치가 있으면 3단계로 되돌아간다.

### 배치 규칙

프레임끼리, 그리고 섹션끼리 겹치지 않게 둔다. 2026-07-31 이전에는 겹침이 5곳
있었고 그중 3곳은 아래 프레임이 거의 보이지 않는 수준이었다.

- `17:5`에서 `52:2`가 `26:41`을 91% 덮고 있었고 `46:2`는 100% 묻혀 있었다.
- `17:4`에서 `49:2`가 선행 보드 `26:2`를 85%, `50:5`가 `40:2`를 98% 덮고 있었다.
- 섹션 `17:6`이 `17:3`과 3600×817 겹쳐 있었다.

선행 보드 `26:2`·`40:2`는 지우지 않고 `17:4` 하단(y=4900) 부록 대역으로 옮겼다.
섹션 크기는 내용에 맞춰 여백 60~100px만 남긴다 — `17:5`는 6600×5200 중
1520×1800만 쓰고 있어서 어디까지가 내용인지 알 수 없었다.

정리된 교수자 콘솔 시안은 `26:41 · Instructor · Clean operations`다.

`40:2 · Audit · Remaining views`와 `40:25 · Remaining · Clean states`는 stale이 아니다.
각각 `17:4`/`17:5`의 자식으로 살아 있다. 최상위가 아니라 섹션 아래에 있어서 페이지
직속 조회로는 보이지 않을 뿐이다. 노드가 없다고 판단하기 전에 섹션 안까지 확인한다.

이 파일에는 페이지가 3개 있다: `0:1 · Page 1`, `5:2 · 02 · Redesigned Experience`,
`17:2 · 03 · Full App UI UX Loop`. 앱 UI/UX 루프의 기준은 `17:2`다.

### 고친 결함 (2026-07-31)

감사 카드 5개의 헤드라인이 발견 제목 대신 우선순위를 두 번 출력하고 있었다
(`50:5`/`50:14` "P1  P1", `50:8`/`50:11` "P0  P0", `50:17` "P2  P2 · 공통 시스템 개선").
보드를 만든 스크립트가 `card(x, y, w, h, title, body, severity)`에 제목 대신
우선순위를 넘겼고, 실제 제목은 본문 첫 줄로 밀려 본문과 구분되지 않았다.
헤드라인을 `우선순위 + 발견 제목`으로 복구하고 본문의 중복 줄을 제거했다.
프레임 이름도 같이 정정했다. `51:4`/`51:7`은 다른 함수로 만들어져 원래 정상이었다.

보드를 스크립트로 다시 만들 때는 `card()`의 인자 순서를 확인할 것 —
제목과 우선순위를 바꿔 넘겨도 조용히 그럴듯한 카드가 나온다.

교수자 콘솔 감사는 별도 파일 `uumUXm2LdFzra2VM5UDxiJ`(DTS Instructor Console — Hyeji UX Audit)에도 있다. 두 파일이 갈라지지 않도록, 화면 구조의 기준은 항상 `4WIyk1eds5QF6B8fV9fpTU`로 둔다.

그 파일은 2026-07-31 판독 기준 페이지 1개(`0:1`)에 프레임 2개뿐이다 —
`1:2 · 디자인 텐션 스튜디오`(앱 캡처)와 `3:2 · DTS / 교수자 운영 콘솔 / Hyeji`(시안),
둘 다 1440×1000. 단일 화면 탐색용이라 SSoT가 갈라질 위험은 낮다.

- 모든 화면에서 텍스트가 잘리지 않고 주요 CTA가 한눈에 보여야 한다.
