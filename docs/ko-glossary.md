## 0. 말투(레지스터) 규칙

- **해요체로 통일**합니다. (예: "없습니다" → "없어요", "할 수 있습니다" → "할 수 있어요")
- 버튼/메뉴 등 행동 유도는 **명사형 "...하기"** 로 통일합니다. (예: 질문하기, 메모 저장, 열기, 이어하기)
- 학부생 대상 도구이므로 부드럽고 간결하게. 한 문장에 한 가지 행동만.

## 0.7. 혜지 6/5 피드백 적용 (이번 라운드)

혜지 박사님 6/5 의견 6건을 앱(`app.js`/`index.html`)·가이드·튜토리얼 전반에 반영했습니다.

1. **tension → 쟁점** 으로 통일 (갈등/쟁점 중 "쟁점" 선택). 한국어 문자열 전수 치환.
2. **map → 맵** 으로 통일 ("지도" 전수 치환).
3. **"견줘 보세요" → "비교해 보세요"** (`comparePrompt`).
4. **숫자 그대로 노출 문제 해소** — "주요 쟁점" 본문에서 "교사 업무 부하가 62이다"처럼
   점수만 보이던 표현을 말로 풀었습니다. `koBandWord()` 헬퍼가 0–100을
   **매우 낮은 / 다소 낮은 / 보통인 / 다소 높은 / 매우 높은** 5단계로 바꿔
   "지금 교사 업무 부담이 다소 높은 편이에요(100점 만점에 62점)."처럼 읽히게 했습니다.
   ("프라이버시가 70 아래로 떨어지면" → "프라이버시가 낮아지면(대략 70점 아래)")
5. **관점명 IT 시스템 → 에듀테크** (대안 에듀테크 기업/기술 중 "에듀테크" 선택). 칩·온보딩·개념설명·근거 라벨 전반.
6. **상충 관계 탭 라벨 불일치 수정** — 레이더 축이 "업무 부담"으로 표기됐지만 실제 값은
   여유 시간(100−부담)이라 바 그래프("여유 시간")와 어긋났습니다. 레이더 축도
   **"교사 여유 시간"** 으로 맞춰 두 시각화를 일치시켰습니다. (입력 슬라이더는 "교사 업무 부담" 유지 — 올리면 여유 시간이 줄어드는 입력값) + "교수자"→"교사" 표기 정정.

### 같은 취지로 추가 정리 (일맥상통 확대 — 혜지 6/5 지시 "전체적으로 모두 수정")

- **교사 vs 교수자 잔여 정정** — 케이스 속 교사를 가리키는 `signalTeacherLoad`(교수자 부담→교사 부담),
  `nodeTitleTeacher`(교수자 부담 핫스팟→교사 부담 핫스팟), `landingHumanBody`(교수자·학생→교사·학생) 정정.
  (도구를 운영하는 사람은 그대로 "교수자" 유지)
- **맵 조사(助詞) 정리** — 지도→맵 일괄 치환 과정에서 "지도를→맵를", "지도가→맵가", "지도로→맵로"처럼
  어색해진 조사를 맵을/맵이/맵으로로 모두 바로잡음(7곳).
- **스웜 노드 상세(툴팁) 한국어화** — `describeNodeIssue`의 노드 분기들이 한국어 화면에서도 영어 문장과
  생짜 점수("Teacher load 62")로 노출되던 것을 전부 한국어 + 밴드 표현으로 지역화
  (예: "교사 업무 부담 · 다소 높음(62점)"). 이해관계자 라벨/상태/요약도 번역 키로 연결.
- **숫자 밴드 적용 확대** — `koBandWord()`(매우 낮은~매우 높은 5단계)를 주요 쟁점 본문뿐 아니라
  스웜 노드 kicker에도 적용해 생짜 점수 노출을 제거.
- 남은 범위(이번 커밋 제외): `evidenceLensTitle` 등 "{Label} lens:" 영어 골격, 생성 케이스 메타데이터
  일부는 더 깊은 영어 서브시스템이라 별도 라운드로 분리.

### 이해관계자 렌즈 순서 (4개로 확정)

화면·온보딩·개념 설명 전반에서 **교사 → 학생 → 에듀테크 → 행정** 순서로 통일했습니다.
근거: 제웅 6/4 과제 안내 메일의 "four stakeholder lenses (Teacher, Student, IT, Administration)".
(이전: 앱=교사/IT/학생 3개, 덱=선생님/사회/학생 3개 — 자료마다 달라 통일했습니다.)

## 2. 이번에 적용한 수정 (요약)

1. **렌즈 4개로 통일** — `conceptHelpBody`, `perspective*Short`(+ `perspectiveAdminShort` 신설),
   `studentOnboardingStep3`를 교사·학생·에듀테크·행정으로. 개념 설명 카드에 "행정" 항목 추가. (IT→에듀테크는 §0.7)
2. **교사 vs 교수자 구분** — `stakeholderTeacher`를 "교수자"→"교사"로 바로잡음. (상충 탭 라벨 `teacherLoadLabel`/`teacherSlack`도 6/5에 "교사"로 정정 — §0.7)
3. **개념어 통일** — `topTensions`, `priorityTensions`, `noTensions`, `caseTension`,
   `tensionScaleHint` 등에서 혼용을 정리. **6/5에 최종 "쟁점"으로 통일(§0.7)**. (`keyConcerns`는 "주요 우려"로 분리)
4. **맵 레이어 표현** — 내 화면→**내 보기**, 전체 화면→**학급 보기**;
   공개 범위 옵션은 **학급에 공개**(`shareToClass`)로 분리.
5. **해요체 통일** — 학생이 보는 빈 상태/안내/상태 메시지 다수를 해요체로.
6. **홈 대시보드 문구 신설** — `home*` 키 일괄 추가(아래 3절).
