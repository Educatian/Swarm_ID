## 0. 말투(레지스터) 규칙

- **해요체로 통일**합니다. (예: "없습니다" → "없어요", "할 수 있습니다" → "할 수 있어요")
- 버튼/메뉴 등 행동 유도는 **명사형 "...하기"** 로 통일합니다. (예: 질문하기, 메모 저장, 열기, 이어하기)
- 학부생 대상 도구이므로 부드럽고 간결하게. 한 문장에 한 가지 행동만.

### 이해관계자 렌즈 순서 (4개로 확정)

화면·온보딩·개념 설명 전반에서 **교사 → 학생 → IT → 행정** 순서로 통일했습니다.
근거: 제웅 6/4 과제 안내 메일의 "four stakeholder lenses (Teacher, Student, IT, Administration)".
(이전: 앱=교사/IT/학생 3개, 덱=선생님/사회/학생 3개 — 자료마다 달라 통일했습니다.)

## 2. 이번에 적용한 수정 (요약)

1. **렌즈 4개로 통일** — `conceptHelpBody`, `perspective*Short`(+ `perspectiveAdminShort` 신설),
   `studentOnboardingStep3`를 교사·학생·IT·행정으로. 개념 설명 카드에 "행정" 항목 추가.
2. **교사 vs 교수자 구분** — `stakeholderTeacher`를 "교수자"→"교사"로 바로잡음.
3. **"긴장" 용어 통일** — `topTensions`, `priorityTensions`, `noTensions`, `caseTension`,
   `tensionScaleHint` 등에서 쟁점/갈등/상충 혼용을 "긴장"으로 정리. (`keyConcerns`는 "주요 우려"로 분리)
4. **지도 레이어 표현** — 내 화면→**내 보기**, 전체 화면→**학급 보기**;
   공개 범위 옵션은 **학급에 공개**(`shareToClass`)로 분리.
5. **해요체 통일** — 학생이 보는 빈 상태/안내/상태 메시지 다수를 해요체로.
6. **홈 대시보드 문구 신설** — `home*` 키 일괄 추가(아래 3절).

## 4. 함께 확정할 열린 결정 (혜지 박사님 확인 요청)

1. **"긴장" vs "쟁점"** — 핵심 개념어를 "긴장"으로 통일했습니다.
   학부생에게 "쟁점/긴장 지점"이 더 와닿는다면 일괄 교체할 수 있어요. (현재 기본값: 긴장)
2. **"케이스" vs "사례"** — 외래어 "케이스" 유지 중. 학술 톤으로 "사례"가 낫다면 변경 가능.
3. **"노드" vs "항목"** — 지도 위 원을 "노드"로. 더 쉬운 말이 필요하면 "항목"으로.
4. **"감성 실험실"(sandbox)** — 코드상 sandbox 뷰의 한국어 라벨. 기능 의도에 더 맞는 이름이 있으면 알려주세요.
5. **홈 진입 기본값** — 학생은 홈 대시보드로 진입하도록 했습니다(교수자는 기존 워크스페이스 유지).
   네트워크 잠금(network-only) 케이스에서는 홈의 "맵 살펴보기"만 활성화되고 나머지 카드는 비활성으로 표시됩니다.
