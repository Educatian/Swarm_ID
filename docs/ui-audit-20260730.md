표시 로직 자체는 맞았다 — `hidden = !(activeRole === "admin" && activeCase)`.

점이다. `.reflection-block { display: grid }`가 그것을 이겨서, **속성은 true인데 화면에는
그대로 남았다.** 교수자 전용 학급 분석 UI가 학습자에게 노출되고 있었다.

한 컴포넌트만 고치는 대신 속성이 항상 이기도록 전역 가드를 넣었다:

```css
[hidden] { display: none !important; }
```

검증: 학습자 `display: none` / 렌더 안 됨, 교수자 정상 표시, 문서 전체에서
`[hidden]`인데 표시되는 요소 **0건**. smoke `24/24`.

크롬으로 나갔다가 순환한다. 트랩 없음. 포커스 가능 요소 11개 중 8개만 도달하는 것은
